## 📖 Overview

**FolVid** is a powerful, browser-based video player and library manager. It scans a local `videos/` directory on your server, automatically indexes content, and presents a sleek, responsive interface for browsing, searching, and playing media—no manual manifest files required.

Designed for both short clips and long-form content, FolVid features a custom-built video player with storyboard seek previews, HLS streaming support, playlist management, and full keyboard control.

---

## ✨ Features

### 🎥 Core Playback

- **Custom Video Player** — Built from the ground up using the HTML5 Video API with a fully custom control bar.
- **Precise Controls** — Play/Pause, Seek, Timeline Scrubbing, Volume, and Playback Rate (0.5x – 2x).
- **Storyboard Thumbnails** — Hover over the timeline to see frame previews generated by FFmpeg.
- **HLS Support** — Native playback of HLS streams alongside standard MP4/WebM/MOV files.
- **Audio Visualizer** — Real-time audio frequency visualization during playback.

### 🗂️ Library & Management

- **Dynamic Directory Scanning** — Backend auto-discovers videos on every request; just drop files into the folder and refresh.
- **Search & Filter** — Instantly search by filename and filter your library.
- **Upload Modal** — Drag-and-drop or select files to upload directly through the web UI.
- **Rename Files** — Right-click any video to rename it without touching the server.
- **Video Metadata** — FFmpeg extracts resolution, file size, duration, codec info, and auto-generated thumbnails.

### 📋 Playlists

- **Create & Manage Playlists** — Organize videos into custom playlists.
- **Continuous Playback** — Automatically play the next item in your playlist.

### 🎨 UI / UX

- **Responsive Design** — Optimized for desktop, tablet, and mobile with adaptive layouts.
- **Custom Context Menu** — Right-click on videos or the player for contextual actions.
- **Lucide Icons** — Clean, consistent iconography throughout the interface.
- **Language Switcher** — Full internationalization supporting **English**, **German**, and **Vietnamese** (via `react-i18next`).

### ⚡ Performance & State

- **Zustand + React Context** — Hybrid state management for global stores and localized player context.
- **Persistent Preferences** — Playback speed, volume, and other settings are saved to `localStorage`.
- **Lazy Thumbnails** — Intersection Observer-based lazy loading for video thumbnails in the list.

### ⌨️ Keyboard Shortcuts

| Key     | Action                  |
| ------- | ----------------------- |
| `Space` | Play / Pause            |
| `M`     | Mute / Unmute           |
| `L`     | Loop / Unloop           |
| `← / →` | Seek backward / forward |
| `F`     | Toggle Fullscreen       |

## 🛠️ Installation & Setup

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- [FFmpeg](https://ffmpeg.org/download.html) installed and available in your system `PATH`
- npm (comes with Node)

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/folvid.git
cd folvid
```

### 2. Setup Backend

```bash
cd backend
npm install
mkdir videos
# Copy your video files into the ./videos directory
npm start
```

The backend will run on `http://localhost:4000`.

### 3. Setup Frontend

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

The frontend will run on `http://localhost:5173`.

## ⚙️ Configuration

### Environment Variables (Frontend)

Create a `.env` file in `frontend/` if you need to override the default API URL:

```env
VITE_API_URL=http://localhost:4000
```

### FFmpeg

Ensure the backend can execute `ffmpeg` and `ffprobe`. The backend uses these to:

- Generate video thumbnails
- Extract metadata (dimensions, duration, codec)
- Create storyboard sprite sheets for timeline hover previews

## 📡 API Endpoints

### Static File Serving

| Method | Endpoint                      | Description                                              |
| ------ | ----------------------------- | -------------------------------------------------------- |
| `GET`  | `/videos/:filename`           | Stream video files (MP4, WebM, MOV, etc.)                |
| `GET`  | `/hls/:path`                  | Serve HLS playlist and segment files                     |
| `GET`  | `/cache/thumbs/:filename`     | Serve auto-generated thumbnail images                    |
| `GET`  | `/cache/storyboard/:filename` | Serve storyboard sprite sheets for timeline seek preview |

### REST API

| Method | Endpoint                | Description                                                                                      |
| ------ | ----------------------- | ------------------------------------------------------------------------------------------------ |
| `GET`  | `/api/videos`           | List all indexed videos in the library                                                           |
| `POST` | `/api/upload`           | Upload a new video file to the server                                                            |
| `POST` | `/api/metadata`         | Generate and save video metadata (thumbnails, storyboard, resolution, duration, etc.) via FFmpeg |
| `PUT`  | `/api/videos/:filename` | Rename an existing video file                                                                    |
